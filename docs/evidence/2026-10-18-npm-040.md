## Documentation, scope and recovery

The root setup guide now routes to this qualified release; the documentation
router/map includes this receipt. Architecture describes canonical npm releases
and optional GitHub mirrors. The earlier candidate snapshot is preserved with a
follow-up link. Package usage, implementation, dependencies and release workflow
are unchanged by this documentation slice.

This record establishes library publication and independent registry consumption.
Application adoption and its normal verification belong to the consuming
repository. No application deployment, GitHub release page or binary mirror was
performed for 0.4.0. Existing tags and prior archives remain unchanged.

For a defect, follow the release runbook: publish a checked corrective version,
never rewrite this version. A consumer rollback must restore its complete prior
configuration and lockfile together; replacing only the dependency cannot run
new 0.4.0 configuration exports on the previous release.
