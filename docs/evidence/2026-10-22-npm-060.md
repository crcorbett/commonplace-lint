## Usage and limits

Version 0.6.0 requires Oxlint 1.87.0, 1.88.0 or 1.89.0. Consumers must repeat
`effect-tsgo patch --no-typescript --oxlint` after dependency installation,
normally in their existing `prepare` command. Pinned checker dependencies ship
with the package. Oxlint 1.86.0 is no longer supported by this release.

The accumulation rule suggests immutable Effect operations and has no automatic
fix. It follows statically known local callbacks and aliases; it cannot establish
the behaviour of imported callbacks, mutable aliases or arbitrary later pipe
operations. The package README explains these limits.

This record verifies the library release. Consumer-project adoption and their
integration suites remain separate work. No GitHub release page or binary mirror
was created for 0.6.0. Older published versions and tags remain unchanged.
