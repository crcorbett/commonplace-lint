- Published npm integrity: `sha512-+BRTbAuzS3U4GclmG4Cpdzr7Vo/og4WLBiHTUXFWpFmsoBtNawDEnQaWPEr/r639l2zmc46m28ZAcRQ2g21tGw==`
- Earlier local archive SHA-256: `3b2cc30cf293fad551dd9f0f6717ae64d205a8d9675850d6ed042421c1c60cc8`

The published and local archives are distinct artifacts. Independent comparison
found identical file names, order, types and content for all 69 members. The
local tar members use mode `0600`; CI's members use `0644`. Replacing only those
mode fields and their tar header checksums makes the uncompressed tar streams
equal. A separate npm 11.13.0 pack from a scratch copy with `0644` modes reproduced
the published compressed archive exactly. The original local archive and its
qualification record are preserved; its hash is not the registry hash.
