# npm 0.5.0 release — 21 October 2026

The owner explicitly asked to merge and release after reviewing the style
candidate and latest dependency results. This authorises the library release;
Site and Common Practice adoption remain separate. No credentials, billing,
branch protection or consumer files were changed.

## Documentation and limits

The package README owns usage, supported hosts and each override's reason.
The changelog owns version changes. This dated record owns publication proof;
the documentation router and map link it. Architecture and the release runbook
remain unchanged because the release uses their existing procedure.
There is no application or infrastructure stack to plan, apply or deploy.

The [latest candidate record](2026-10-21-latest-dependencies.md) retains the exact
version comparison and per-consumer results: Site has 76 new findings across
seven rules; Common Practice has 141 across 24. Style also requires consumer
test changes: Site's trial has one failing composition expectation; Common
Practice has that expectation and six lint-fixture acceptance failures. Their
original baselines pass. No consumer code was fixed, committed or adopted.

Consumer adoption, integration suites, public application endpoints, browser
journeys and deployed tracking/workflow checks are outside this library release.
No GitHub binary archive mirror has been created. npm publication is distinct
from a GitHub release page. Existing published versions and tags remain immutable.
For a defect, follow the runbook and publish a checked corrective version rather
than replacing 0.5.0. Consumer rollback must restore its configuration and lockfile
together.
